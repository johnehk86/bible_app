# 03. 데이터 모델 (v2, 2026-10-25)

## 원본 → 앱 데이터
- 원본: `files/DA 1단계 암송구절(아랍어) 음원/DA 1단계 암송구절(한국어-아랍어)_수정 (2).xlsx` + mp3 13개
- `cd app && npm run data` (scripts/build-data.mjs): 엑셀 직접 읽기(내장 zip 해제, 외부 라이브러리 없음)
  → `public/data/passages.json` + `public/audio/<id>.mp3` 복사 + 절 타이밍 계산(mpg123-decoder 로 디코드, 앱과 같은 align)
- 엑셀 형식: 시트 = 구절(시트 순서 = 암송 순서), 시트 이름 `신명기 6장 4-9절`, 4행부터 A 장절 / B 한국어(개역개정) / C 아랍어(Van Dyck, **모음 부호 없음**) / D 아랍어 한국어 발음
- 음원 매칭: 원본 mp3 파일 이름의 성경 이름(줄임말 `마`, `요`, `고전` 포함)과 장 번호
- 새 성경 이름은 build-data.mjs 의 `BOOKS` 에 추가 (id 약어, 아랍어 이름)

## passages.json
```json
{ "title": "DA 1단계 암송구절", "translation": "...",
  "stages": [ { "stage": 1, "name": "DA 1단계", "passages": [
    { "id": "deut_6_4-9", "no": 1, "ref": "신명기 6:4-9", "refAr": "تثنية ٦: ٤-٩",
      "audio": "audio/deut_6_4-9.mp3", "duration": 42.4,
      "verses": [ { "n": 4, "ko": "...", "ar": "...", "pron": "...", "start": 0 } ] } ] } ] }
```
- `start`: 절 시작 초 (자동 계산). `"startFixed": true` 를 넣으면 `npm run data` 를 다시 돌려도 유지
- `audio: null` 이면 "아직 녹음이 없어요" (연속듣기에서는 건너뜀)

## 단계 2: 네비게이토 (2026-10-25 추가)
- 원본: `files/네비 게이토 성경 암송 구절(아랍어) 음원/navigators_180_korean_arabic-v2.xlsx` + 주제 폴더 7개 안 mp3 28개
- 엑셀: 시트 0 = 안내, 시트 1~7 = 주제("1. 하나님을 알아감" …). 3행부터 A 번호 / B 분류(`[A. 예수 그리스도]\n1. 예수님의 신성`) / C 장절 `요한복음 1:1,14 (يوحنا 1: 1، 14)` / D 한국어(**개역한글**) / E 아랍어(SVD, **모음 부호 있음**). **발음 칸 없음**
- 엑셀 229항목(1~5주제 36개씩, 6주제 22, 7주제 27) 중 **녹음 있는 28개만** 앱에 넣음 (사용자 결정). 여러 절 항목(예 6:10,11)은 한 덩어리 = verses 1개, n = "10-11"
- mp3 ↔ 항목: 주제 폴더 번호 + 성경·장·첫 절. 27개 자동 매칭, **`디모데후서 4장 9절.mp3` 는 실제로 4:2** (말소리 덩어리 5개가 4:2 문장부호 5구절과 일치) → `AUDIO_REF_FIX` 로 보정
- passage 추가 필드: `group`(주제 시트 이름), `topic`(분류 한 줄). id = `nav_<약어>_<장>_<절>` (예 `nav_eph_6_10-11`)
- 목록: 탭 "DA 1단계 / 네비게이토", 네비게이토 탭은 주제 제목으로 묶고 항목에 소주제 표시. 연속듣기는 탭별
