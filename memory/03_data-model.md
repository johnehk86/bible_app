# 03. 데이터 모델 (`app/src/data/verses.js`)

## 구조
```js
export const PASSAGES = [
  {
    id: 'deut_6_4-9',                 // 오디오 파일명과 동일한 규칙: 책약어_장_절범위
    reference: '신명기 6:4-9',          // 한국어 참조 (화면 표시용)
    referenceAr: 'تثنية ٦‏:٤-٩',       // 아랍어 참조 (홈 배너/목록/암송 화면 표시)
    audioFile: './assets/deut_6_4-9.mp3',  // public/assets 기준 상대경로
    verses: [
      { verse: 4, ko: '...', ar: '... (AVD, 모음 포함)', timestamp: 0 },
      ...
    ],
  },
  ...
]

export const SPEED_OPTIONS = [0.5, 0.75, 1, 1.25, 1.5]
```

- `timestamp` : 해당 절이 mp3에서 시작하는 시간(초). 첫 절은 항상 0.
- 한글 음가(발음) 필드는 아직 없음 (원본 엑셀에는 있음 → 추후 `pron` 같은 필드로 추가 예정).
- 텍스트 원본: `files/DA 1단계 암송구절(한국어-아랍어).xlsx`

> 주의: 몇몇 구절은 **절 범위 중 일부 절만** 텍스트로 수록되어 있음 (예: 마 5:3,13-14,16 / 시 23:1-6인데 4개 절).
> 파일명(id)은 전체 범위(`mat_5_1-16`)지만 텍스트는 발췌본. mp3가 전체 범위를 읽는지 발췌만 읽는지 확인 필요.
> timestamp가 전부 0인 구절은 앱 내 "타이밍 맞추기"로 사용자가 직접 맞춰야 함 → 확정되면 verses.js에 반영 권장.

## 오디오 에셋
- 원본: `files/DA 1단계 암송구절(아랍어) 음원/*.mp3` (한글 파일명)
- 앱용 사본: `app/public/assets/<id>.mp3` (영문 파일명, 빌드 시 `dist/assets/`로 복사)
- 파일명 규칙: `책약어_장_절범위.mp3` (예: `deut_6_4-9.mp3`)
- 각 mp3는 여러 절을 한 번에 통으로 낭독 (절 단위 분리 파일 아님)
- 신명기 6:4-9 : 42.48초 / mono / 48kHz

## 새 구절 추가 방법
1. mp3를 `app/public/assets/<id>.mp3`로 복사
2. `verses.js`의 `PASSAGES` 배열에 객체 추가 (`id`, `reference`, `referenceAr`, `audioFile`, `verses[]`)
3. 목록 화면은 `PASSAGES`를 자동 순회하므로 추가 작업 불필요
