# 06. 이슈 / 할 일 (v2, 2026-10-25)

## 엑셀 데이터에서 발견한 오타 (앱은 엑셀 그대로 표시 — 사용자 확인 필요)
1. 신명기 6:4 아랍어 첫 단어 `اشمع` → Van Dyck 은 `اسمع` (들으라). 발음도 "이슈마"로 적혀 있음
2. 시편 1:2 아랍어 `يهجث` → `يلهج` (묵상하다)로 보임
3. 시편 1:4 발음에 영문 `Hum` 이 섞임 ("발 Hum 카눌...")
4. 마태복음 7:10 행의 장절 칸이 "요한복음 7:10" → 변환 스크립트가 마태복음으로 처리 (경고 출력)
- 고치는 법: 엑셀 수정 → `npm run data` → 커밋·푸시

## 타이밍 점검 결과 (`npm run check-align`, 절별 발화 속도가 중간값의 1.35배 이상 차이)
- 요한 1장 1~3절, 로마서 23절, 마태 5장 1절, 고전 13장 6절, 시편 1편 1절, 시편 23편 3·6절, 시편 100편 2절
- 요한 1장은 단어별로 보면 절 경계가 문장 끝과 맞음 (1절을 천천히 읽은 것). 나머지도 귀로 확인 필요 → 어긋나면 앱의 타이밍 맞추기 또는 `startFixed`
