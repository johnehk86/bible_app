# 04. 핵심 기능 (v2, 2026-10-25)

사용자용 설명은 `app/README.md` 의 사용법 표 참고. 여기는 구현 메모.

## 구간 반복 (PassageScreen + Looper + Player)
- 구간은 구절별 `bible:ab:<id>` = `{start, end}` (0.1초 단위). 없으면 전체 반복. 전체와 같으면 자동으로 "구간 없음"
- 지정: 절 번호 탭(그 절만, 다시 누르면 해제) / 절로 고르기(select 2개) / 여기부터·여기까지 / A·B 손잡이 드래그 / ±0.1·±0.5
- 시작 > 끝이면 맞바꾸고 토스트, 0.3초 미만이면 거절
- 반복 횟수 ∞/1/3/5/10, 쉬는 시간 0~3초, 속도 0.5/0.75/1/1.25 (우리는 0.5 추가) → `bible:settings`
- 절 구간 = 절 시작 −0.12초 ~ 다음 절 시작 −0.08초
- 검증: 요한 15:12 절 탭 → 99.0~104.7 구간, 끝에서 1초 쉬고 99초로 복귀, "2번째 / ∞"

## 연속듣기 (ContinuousScreen)
- 녹음 있는 구절만, 구절마다 1/2/3번, 구절 사이 쉬는 시간, 속도 → `bible:continuous`, 마지막 위치 `bible:continuousPos:<stage>`
- Looper.onDone → 다음 구절 (마지막이면 1번, "n바퀴째")
- 구절이 바뀔 때만 맨 위로 스크롤 (같은 구절 안에서는 자동 스크롤 없음 — 2026-09-30 사용자 요청 유지)

## 글자 색칠 / 타이밍
- 녹음 = 아랍어 → **아랍어 단어 단위 색칠**(오른쪽→왼쪽 그라데이션), 현재 절 묶음 전체 강조
- 시간 계산 우선순위: 사용자 타이밍(`bible:verseMarks:<id>`) > 데이터 `start`
  1. 화면 열자마자: `timesFromStarts` (절 시작 + 절 안 음절 비례) → 절 강조 즉시 정확
  2. 브라우저 분석 끝나면: `alignAuto` 단어 시간을 `applyMarks` 로 절 시작에 맞춰 보정
- 녹음 맨 앞 제목 읽기 구간에는 강조 없음 (요한 15장 0~3.9초)
- 타이밍 맞추기(더보기): 참고 앱 방식 — 처음부터 재생, 새 절이 시작될 때 "N절 시작" 버튼, 가까운 말소리 시작점에 붙음(snapToOnset), 처음부터 다시/취소, 자동으로 되돌리기. 첫 절 시작은 현재 값 사용(제목 읽기 대응)
- v1 의 "−/+ · 지금" 튜너 방식은 v2 에서 참고 앱의 탭 방식으로 대체됨

## 기타
- 암송 완료 `bible:done`, 마지막 구절 `bible:pos` → 목록의 "이어서 암송하기"
- 보기: 한국어 뜻/발음 보이기·숨기기 (`settings.showKo/showPron`, 연속듣기도 따름)
- 단어 가리기: 아랍어 단어, 구절별 `bible:mask:<id>`
- Media Session(잠금화면 재생/멈춤, 연속듣기는 이전/다음 트랙), 키보드 Space/[/]/Esc
