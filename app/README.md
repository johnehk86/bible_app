# 말씀암송 (한국어 · 아랍어)

아랍어 낭독을 듣고, 원하는 구간(시작~끝)을 정해 **계속 반복**해서 들으며 외우는 앱.
소리가 나오는 동안 **읽고 있는 아랍어 단어가 금색으로 칠해지고**, 지금 읽는 절이 강조된다.
절마다 아랍어 · 한국어 발음 · 한국어 뜻을 함께 보여 준다.

React + Vite 정적 사이트. 서버·DB 없음. PWA(홈 화면 추가, 오프라인 재생).
배포: GitHub `johnehk86/bible_app` → Cloudflare Pages 자동 배포 (루트 디렉터리 `app`, 빌드 `npm run build`, 출력 `dist`).

## 실행

```bash
npm install
npm run dev       # 개발 서버 (http://localhost:5173)
npm run build     # dist/ 생성
npm run preview   # 빌드 결과 미리보기 (서비스 워커 포함 확인용)
```

## 사용법 (구절 화면)

| 하고 싶은 것 | 방법 |
|---|---|
| 전체 반복 | 큰 재생 버튼 |
| 한 절만 반복 | 본문 왼쪽 **절 번호** 누르기 (한 번 더 누르면 해제) |
| 여러 절 반복 | 구간 반복 → **절로 고르기** `3절 ~ 5절` |
| 원하는 지점 반복 | 재생 중 **여기부터 / 여기까지**, 진행바의 **A·B 손잡이** 끌기, ±0.1 / ±0.5초 미세조절 |
| 반복 횟수·쉼·속도 | 반복 설정: 횟수 ∞/1/3/5/10, 반복 사이 쉬는 시간 0~3초, 속도 0.5/0.75/1/1.25배(음높이 유지) |
| 그 단어부터 듣기 | 아랍어 단어 누르기 |
| 한국어 뜻·발음 숨기기 | 더보기 → 보기 |
| 외웠는지 확인 | 더보기 → **단어 가리기** (가린 아랍어 단어는 소리가 읽는 순간 드러남) |
| 차례로 계속 듣기 | 목록 → **전체 연속듣기** (구절마다 1~3번, 끝나면 처음부터) |

키보드: `Space` 재생/일시정지, `[` 여기부터, `]` 여기까지, `Esc` 정지.
구간·설정·암송 완료는 기기 브라우저(localStorage, 키 앞에 `bible:`)에 저장된다. 기기마다 따로다.

## 본문·녹음 고치기 / 추가하기 (앱 코드 수정 불필요)

원본은 `../files/` 의 두 폴더(**엑셀 + mp3**)이고, 목록의 탭 두 개가 된다.

**DA 1단계** — `files/DA 1단계 암송구절(아랍어) 음원/`
- 엑셀: 시트 하나 = 구절 하나, 시트 순서 = 암송 순서. 시트 이름 `신명기 6장 4-9절`, `시편 23편 1-6절`
- 4행부터: A 성경 구절(`신명기 6:4`) · B 한국어 · C 아랍어 · D 아랍어 한국어 발음
- mp3: 같은 폴더, 파일 이름에 성경 이름과 장 번호 (`요한복음 15장 ...mp3`, `마 5장 ...mp3`)

**네비게이토** — `files/네비 게이토 성경 암송 구절(아랍어) 음원/`
- 엑셀: 첫 시트는 안내, 그다음 주제 시트 7개. 3행부터 A 번호 · B 분류 · C 장절 `요한복음 1:1,14 (يوحنا 1: 1، 14)` · D 한국어 · E 아랍어(모음 부호)
- mp3: 주제 폴더(`1. 하나님을 알아감/`) 안에 `갈라디아서 4장 6절.mp3`, `에베소서 6장 10절에서 11절.mp3`
- **녹음이 있는 항목만** 앱에 들어간다 (엑셀 229항목 중 현재 28개). mp3 를 주제 폴더에 넣고 다시 돌리면 자동으로 늘어난다
- 파일 이름이 잘못된 녹음은 `scripts/build-data.mjs` 의 `AUDIO_REF_FIX` 에 적는다 (예: `디모데후서 4장 9절.mp3` → 실제는 4:2)

순서:
1. 엑셀을 고치거나 mp3 를 넣는다
2. `npm run data` → `public/data/passages.json` 생성, mp3 를 `public/audio/<id>.mp3` 로 복사, **절 타이밍 자동 계산** (끝에 "확인할 것" 경고 출력)
3. 커밋·푸시하면 배포 끝

새 성경 이름은 `scripts/build-data.mjs` 의 `BOOKS`(id 약어, 아랍어 이름)에 한 줄 추가한다.

## 글자 색칠은 어떻게 맞추나

녹음에는 절·단어별 시간 정보가 없어서 녹음을 분석해 추정한다 (`src/lib/align.js`).

1. 소리 크기를 10ms 단위로 재서 **짧은 쉼**들을 찾는다.
2. 쉼 사이 말소리 덩어리를 아랍어 단어들에 순서대로 짝짓는다. 단어 길이는 **한국어 발음 열의 음절 수**(DA), 발음이 없으면 **모음 부호 수**(네비게이토)로 어림한다
   (모음 부호 없는 아랍어 글자 수보다 실제 발음 길이를 잘 나타냄). 긴 쉼은 절 끝·쉼표 뒤를 선호한다.
3. 녹음 맨 앞에서 **장절 제목을 읽는 경우**(예: 요한복음 15장)는 앞쪽 말소리를 제목으로 보고 뺀다.

- 절 시작 시각은 `npm run data` 가 미리 계산해 `passages.json` 의 `start` 에 넣는다 → 화면을 열자마자 절 강조가 맞게 동작
- 단어 단위는 구절을 열 때 브라우저가 녹음을 분석해 다듬는다 (절 시작 시각에 맞춰 보정)
- 어긋나면 앱의 **더보기 → 타이밍 맞추기**: 재생을 들으며 새 절이 시작될 때 버튼을 누른다 (그 기기에만 저장)
- 모두에게 고정하려면 `passages.json` 에서 그 절의 `start` 를 고치고 `"startFixed": true` 를 넣는다 (다시 `npm run data` 해도 유지)

점검:

```bash
npm run check-align              # 전체 구절 요약 (제목 읽기 여부, 절별 속도가 튀는 곳)
npm run check-align -- jn_1_1-18 # 한 구절의 단어별 시간
```

## 저작권 안내

- 한국어 본문은 **개역개정**(저작권 대한성서공회)이다. 누구나 접근할 수 있게 공개 배포하기 전에 이용 허가 절차를 확인해야 한다.
- 네비게이토 한국어 본문은 **개역한글**이다.
- 아랍어는 Van Dyck 역본, 발음 표기와 녹음은 사용자가 준비한 자료다. 엑셀에서 옮긴 것이라 오타가 있을 수 있다.
